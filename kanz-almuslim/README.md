# كنز المسلم 2.0

طريقة جديدة للتسبيح ومحفّزة لروح المنافسة بين الأصدقاء والمسلمين حول العالم.
إعادة بناء كاملة لتطبيق iOS القديم (Objective-C، 2016–2018) بـ **Flutter** ليعمل على **iPhone و Android**.

![الشاشات](test/screenshots/out/01_tasbeeh.png)

## الميزات
- **التسبيح**: اسحب العمود للأعلى (أو المس السبحة)، اهتزاز عند ٣٣، تهنئة وصوت عند كل ١٠٠.
- **الأذكار**: الأذكار العشرة الأصلية مع إمكانية الإضافة والتعديل والحذف والترتيب.
- **السجل**: آخر ٣٠ يوماً مع تفصيل كل يوم، ومجموع اليوم والأسبوع والشهر.
- **الاشعارات**: تذكير تلقائي كل عدد من الدقائق، وتذكير مخصص لأذكار محددة، وعدم الإزعاج. **بدون أي تكرار.**
- **الترتيب**: أكثر الذاكرين اليوم / الأسبوع / الشهر / الكل، عالمياً أو بين الأصدقاء، مع Game Center و Play Games.
- **الحساب**: الدخول بـ Apple أو Google (اختياري)، تعديل الاسم، حذف الحساب.
- **الأصدقاء**: رمز صداقة من ٦ أحرف، طلبات صداقة، ومحادثة.
- **نفس تصميم النسخة الأصلية**: السبحة بـ ٣٣ حبة، أعمدة السحب، الشريط السفلي (سبحه / السجل / الاشعارات / الاعدادات)، والألوان مأخوذة من صور التطبيق القديم.
- الاشتراك ودعم التطبيق (نفس منتجات الشراء القديمة)، عربي وإنجليزي.

## ما الذي أُصلح من النسخة القديمة
| المشكلة | السبب في الكود القديم | الحل |
|---|---|---|
| ٣–٤ تنبيهات في نفس اللحظة | `deleteRandomNotification` فيها `break` فتلغي تنبيهاً واحداً من ٦٤ ثم تضيف ٦٤ جديدة | كل جدولة تلغي **كل** التنبيهات وتعيد البناء من الإعدادات (`NotificationService.rescheduleAll`) |
| تنبيهات تتراكم كل ساعة | `didReceiveLocalNotification` يضيف دفعة جديدة مع كل تنبيه | لا يوجد أي مسار يضيف فوق الموجود |
| تذكيرات لا تُحذف أبداً | `reEnableNotification` يستخدم متغيراً فارغاً فيُنتج معرّفاً خاطئاً | معرّفات ثابتة ومحسوبة |
| ضياع التذكيرات المخصصة | `cancelAllLocalNotifications` عند كل فتح | الجدول يُبنى من الإعدادات المحفوظة |
| أصوات فوق بعض | مشغّل صوت جديد لكل لمسة | مشغّل واحد يوقف السابق (`AudioService`) |
| إغلاق مفاجئ | قسمة على صفر عند مدة = 0 | المدد من قائمة ثابتة |
| السيرفر | `http://kanz.sci3ntist.com` غير مشفّر ومتوقف | Firebase + قواعد حماية مختبرة |

## البنية

```
lib/
  main.dart, app.dart, theme.dart, l10n.dart, models.dart

  services/

  screens/                      الشاشات
firebase/                       قواعد Firestore والفهارس واختباراتها
```
