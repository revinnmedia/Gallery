# أصوات الأذكار

الأصوات الأصلية موجودة في مجلد Dropbox للنسخة القديمة (`KanzAlMuslim/*.mp3`).
أسماؤها أرقام عشوائية (مثل `dc8e65c1aa7adf4800850cc88d321d29.mp3`).

## ١) أصوات التسبيح داخل التطبيق
انسخ الملفات إلى `assets/sounds/` مع إضافة `s_` في بداية الاسم:

```
dc8e65c1aa7adf4800850cc88d321d29.mp3  →  assets/sounds/s_dc8e65c1aa7adf4800850cc88d321d29.mp3
```

السبب: أندرويد يرفض أسماء الموارد التي تبدأ برقم.
قائمة الأسماء المستخدمة موجودة في `lib/data/defaults.dart`.
أي ملف ناقص لا يسبب مشكلة: التسبيح يعمل بدون صوت لذلك الذكر.

## ٢) أصوات التنبيهات (اختياري)
صوت التنبيه يحتاج نسخة مستقلة لكل منصة:

- **أندرويد:** نفس ملفات mp3 في `android/app/src/main/res/raw/` (بنفس أسماء `s_...`).
- **iOS:** حوّل كل ملف إلى `.caf` (مدة أقل من ٣٠ ثانية) وأضفه لمشروع Xcode داخل Runner:
  ```bash
  afconvert -f caff -d LEI16 s_xxx.mp3 s_xxx.caf
  ```

بعدها غيّر `soundsBundled` إلى `true` في `lib/services/notification_service.dart`.
إلى أن يتم ذلك، تستخدم التنبيهات صوت الجهاز الافتراضي.

يوجد سكربت يجهّز الصيغتين معاً: `tool/prepare_sounds.sh`.
